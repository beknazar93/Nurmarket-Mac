# NurMarket Kassa для macOS — тестовая версия 1.17.64

**Только для тестировщиков.** Сборка не подписана Apple, поэтому первый запуск делается по инструкции ниже. Автообновления на Mac нет: новую версию нужно скачивать вручную.

## 1. Какой файл скачать
Меню  → «Об этом Mac».
- Написано **Чип Apple M1 / M2 / M3 / M4** → файл `nurmarket-kassa-macos-arm64-1.17.64.zip`
- Написано **Процессор Intel** → файл `nurmarket-kassa-macos-x64-1.17.64.zip`

Скачать: https://github.com/beknazar93/Nurmarket-Mac/releases/tag/macos-1.17.64 (раздел Assets внизу страницы).

## 2. Установка
1. Откройте скачанный `.zip` двойным щелчком (распакуется в «Загрузки»).
2. Перетащите **NurMarket Kassa.app** в папку **Программы**.
3. Откройте программу **Терминал** (Launchpad → Другие → Терминал, или Spotlight: `Терминал`).
4. Вставьте две команды, после каждой нажмите Enter:

```
xattr -cr "/Applications/NurMarket Kassa.app"
codesign --force --deep -s - "/Applications/NurMarket Kassa.app"
```

Первая снимает пометку «скачано из интернета», вторая ставит локальную подпись. **На Mac с чипом Apple без второй команды программа не запустится.** Пароль или сообщений об успехе Терминал не просит.

## 3. Первый запуск
1. Откройте **Программы → NurMarket Kassa**.
2. Если macOS пишет, что программу нельзя открыть: правый щелчок по программе → **Открыть** → **Открыть**. Или «Системные настройки → Конфиденциальность и безопасность» → внизу кнопка **«Всё равно открыть»**.
3. Войдите логином и паролем NurCRM, как на Windows.
4. Данные кассы хранятся в `~/Library/Application Support/NurMarketKassa`.

## 4. Программа владельца
Откройте Терминал и выполните:
```
open -n -a "NurMarket Kassa" --args --owner
```
Либо запустите файл `nurmarket-owner.command` из архива (при первом запуске: правый щелчок → Открыть).

## 5. Клавиши
**Cmd** работает вместо Ctrl: Cmd+K — поиск раздела, Cmd+V — вставка и т. д.

## 6. Обновление
Скачайте новый архив, закройте программу, замените **NurMarket Kassa.app** в «Программах» и снова выполните две команды из шага 2. Данные кассы сохранятся.

## 7. Если не получается
| Сообщение | Что делать |
|---|---|
| «Приложение повреждено» | Выполните `xattr -cr "/Applications/NurMarket Kassa.app"` ещё раз |
| Программа закрывается сразу на Mac с чипом Apple | Выполните `codesign --force --deep -s - "/Applications/NurMarket Kassa.app"` |
| «Нельзя открыть, так как разработчик не определён» | Шаг 3.2 (Открыть / Всё равно открыть) |
| Скачали не тот файл | Сверьтесь с шагом 1 |

## 8. Что пока не работает на Mac
Автообновление, встроенный сайт, печать этикеток и ценников и графический чек (через System.Drawing), голосовой ввод. Печать чека на принтер не проверена на реальном оборудовании. О любой ошибке сообщайте разработчику.
